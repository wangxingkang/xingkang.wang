# IDE

## 编辑器

- [lapce](https://github.com/lapce/lapce) 代码编辑器
- [zed](https://github.com/zed-industries/zed) IDE
- [sidex](https://github.com/Sidenai/sidex) 基于 Tauri 重构的 VS Code。架构保持一致，体积缩减 96%。目前为早期版本
- [CotEditor](https://github.com/coteditor/CotEditor) 适用于 MacOS 的轻量级纯文本编辑器
- [cate](https://github.com/0-AI-UG/cate) 一款空间式桌面集成开发环境，拥有可无限延展的画布，支持代码编辑、终端、浏览器与 Git 操作

## 远程开发

- [openvscode-server](https://github.com/gitpod-io/openvscode-server) 在远程机器上运行原版 VS Code，可通过现代化网页浏览器，随时随地、从任意设备访问。

## VS Code

### 插件

- [vscode-office](https://github.com/cweijan/vscode-office) 让 VS Code 支持预览 PDF、Excel、Word 等格式文件，并新增所见即所得的 Markdown 编辑器
- [turbo-console-log](https://github.com/Chakroun-Anas/turbo-console-log) 自动化日志工具
