# Uni

## 官方资源

- [官网](https://uniapp.dcloud.net.cn)
- [uni](https://github.com/dcloudio/uni-app) react 仓库

## 数据可视化

- [uni-echarts](https://github.com/xiaohe0601/uni-echarts) 🪀 适用于 uni-app 的 Apache ECharts 组件（仅支持 Vue 3）

## 组件库

- [wot-ui](https://wot-ui.cn) 高颜值、轻量化的 uni-app 组件库
- [uni-ui](https://github.com/dcloudio/uni-ui) 基于 uni-app 的、全端兼容的、高性能UI框架
- [uview-plus](https://uview-plus.jiangruyi.com) 多平台快速开发的UI框架
- [nutui-uniapp](https://github.com/nutui-uniapp/nutui-uniapp) 京东风格的轻量级移动端组件库

## 组件

- [lucky-canvas](https://github.com/buuing/lucky-canvas) 基于 TS + Canvas 开发的【大转盘 / 九宫格 / 老虎机】抽奖插件
- [z-paging](https://github.com/SmileZXLee/uni-z-paging) 下拉刷新、上拉加载

## 开发模版

- [wot starter](https://starter.wot-ui.cn)
- [unibest](https://codercup.github.io/unibest-docs)
- [vitesse-uni-app](https://github.com/uni-helper/vitesse-uni-app)
- [uniapp-vue3-template](https://github.com/oyjt/uniapp-vue3-template)
- [uni-vue3](https://github.com/vue-rookie/uni-vue3) uni-app + Vue 3 项目模板，聚焦跨端开发体验与工程化实践
- [uni-app-vite-vue3-tailwind-vscode-template](https://github.com/sonofmagic/uni-app-vite-vue3-tailwind-vscode-template)

## 其他

- [uni-network](https://github.com/uni-helper/uni-network) 为 uni-app 打造的基于 Promise 的 HTTP 客户端
- [uni-use](https://uni-helper.js.org/uni-use/guide/installation) uni-app 组合式工具集
- [uni-ku-root](https://uni-ku.js.org/projects/root/introduction) 一个模拟 App.vue 原有能力的根组件插件
- [bundle-optimizer](https://github.com/uni-ku/bundle-optimizer) 🦾 Uniapp Vue3 版本的分包优化实现
