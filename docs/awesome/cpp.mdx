# C/C++ 开发

## 库

- [cpp-httplib](https://github.com/yhirose/cpp-httplib) 一个仅含头文件的 C++ HTTP/HTTPS 服务端与客户端库
- [abseil-cpp](https://github.com/abseil/abseil-cpp) Abseil 通用库（C++）
- [fmt](https://github.com/fmtlib/fmt) 快速且类型安全的现代 C++ 格式化库

## 图形与视觉

- [lvgl](https://github.com/lvgl/lvgl) 嵌入式图形库，为任何 MCU、MPU 和显示类型创建精美的用户界面
- [opencv](https://github.com/opencv/opencv) 计算机视觉库
- [skia](https://github.com/google/skia) 2D 图形库，可用于绘制文字、几何图形与图像

## 游戏开发

- [box2d](https://github.com/erincatto/box2d) 用于游戏的 2D 物理引擎

## 语言运行时

- [QuickJS](https://github.com/bellard/quickjs) 轻量且可嵌入的 JavaScript 引擎
- [MQuickJS](https://github.com/bellard/mquickjs) 面向嵌入式系统的 Micro QuickJS JavaScript 引擎，约 10 KB RAM 即可运行

## 系统与虚拟化

- [libkrun](https://github.com/libkrun/libkrun) 提供 KVM/HVF 虚拟化进程隔离能力的动态库，用简单 C API 嵌入轻量 VMM

## 测试

- [Catch2](https://github.com/catchorg/Catch2) C++ 测试框架
