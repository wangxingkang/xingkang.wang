    #预处理器

    • less 动态样式表语言
    • sass Sass 是全球最成熟、稳定且功能强大的专业级 CSS 扩展语言

    #原子化

    • tailwindcss 一款面向快速 UI 开发的实用优先 CSS 框架
    • unocss 一款即时按需原子化 CSS 引擎

    • emotion
    • styled-components
    • @ant-design/cssinjs
    • vanilla-extract 零运行时 TypeScript 样式表

    #Tailwind CSS

    • daisyui 最受欢迎的免费开源 Tailwind CSS 组件库
    • @toolwind/corner-shape 为 CSS 的 corner-shape 属性及其各角独立属性（例如 corner-top-left-shape）提供一流的工具类
    • tw-shimmer 用于实现微光闪烁效果的 Tailwind CSS v4 插件
    • tailwindcss-animate
    • tw-animate-css 兼容 TailwindCSS v4.0 的 tailwindcss-animate 替代方案
    • tailwind-variants Tailwind CSS 一流变体接口
    • tailwind-scrollbar Tailwind CSS 滚动条插件
    • tailwind-scrollbar-hide
    • @tailwindcss/forms 一款为表单样式提供基础重置的插件，便于通过工具类样式自定义表单元素
    • @tailwindcss/typography 默认排版样式
    • @tailwindcss/line-clamp 将文本在指定行数后进行视觉截断(v4 已内置)
