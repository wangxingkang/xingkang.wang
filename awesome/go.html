    #Go

    收录 Go 开发库、框架与学习资源。数据库、容器及网络工具见运维，自托管应用见自托管。

    #官方资源

    • 官网

    #网络与服务端

    • fasthttp Go 语言的快速 HTTP 包
    • Echo 高性能、可扩展的轻量 Go Web 框架，支持路由、中间件、请求绑定与集中式错误处理
    • wish 轻松打造 SSH 应用
    • webrtc 基于 Go 语言原生实现的 WebRTC 接口
    • encore 用于构建高可靠性、类型安全的分布式系统，并支持声明式基础设施配置的开源框架
    • go-zero 一款配备 CLI 工具、用于提升开发效率的云原生 Go 微服务框架
    • ws 适用于 Go 语言的轻量级 WebSocket 库

    #数据与搜索

    • bleve 现代 Go 索引与搜索库，支持文本、数值、地理空间和向量检索
    • chromem-go 可嵌入型 Go 向量数据库，拥有类 Chroma 操作接口，且无任何第三方依赖

    #AI 开发

    • go-sdk 这是 ** 模型上下文协议（MCP）** 服务端与客户端的官方 Go 软件开发工具包，由我方与谷歌联合维护

    #终端界面

    • glamour 为命令行应用提供基于样式表的 Markdown 渲染能力
    • bubbles 适用于 Bubble Tea 的终端交互界面（TUI）组件
    • lipgloss 用于美化终端布局的样式定义
    • huh 构建终端表单与交互提示框
    • bubbletea 终端交互界面开发框架

    #日志

    • log 轻量多彩的 Go 语言日志库

    #文档处理

    • html-to-markdown 将 HTML 转换为 Markdown。甚至支持整个网站，并且可通过规则进行扩展

    #认证与权限

    • casbin 一款支持 ACL、RBAC、ABAC 等访问控制模型的 Go 语言权限控制库

    #语言与编译

    • xgo 一门读起来如同通俗英语的编程语言，可以复用 C/C++、Go、Python 以及 JavaScript/TypeScript 中的已有资源，打造统一的软件工程生态

    #学习

    • codeforces-go 算法竞赛模板库
