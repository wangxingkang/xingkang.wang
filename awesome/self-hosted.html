    #自托管

    #个人云

    • CasaOS 一套简洁易用、设计雅致的开源个人云系统
    • alist 一个支持多存储的文件列表/WebDAV程序，使用 Gin 和 Solidjs
    • OpenList 开源的网盘管理神器
    • syncthing 开源持续文件同步工具
    • ezshare 可在局域网内轻松共享文件、文件夹与剪贴板 —— 功能类似谷歌云盘，但无需联网
    • WechatOnCloud 在自己的 NAS / 服务器上运行「服务端微信」，多端浏览器共享同一个微信会话

    #协作

    • mattermost Mattermost 是一个开源平台，在整个软件开发生命周期中提供安全协作
    • codimd 全平台实时协作 Markdown 笔记工具
    • plane 现代化项目管理平台，可用于管理任务、迭代周期、文档和问题分类处理
    • discourse 论坛系统
    • joplin 一款注重隐私的笔记应用，支持多端同步

    #网络

    • pi-hole 互联网广告的 “黑洞” 拦截器
    • AdGuardHome 面向全家设备的开源 DNS 广告与跟踪拦截服务，支持自托管和网络级过滤
    • dnsmasq 上游 dnsmasq 仓库镜像，提供轻量级 DNS、DHCP、路由器通告和网络启动服务
    • 3x-ui 支持多协议和多用户的 Xray 管理面板，具备到期天数、流量及 IP 限制功能（支持 Vmess、Vless、Trojan、Shadowsocks、Wireguard、Hysteria、隧道、混合模式、HTTP、TUN 模式）
    • DnsServer

    #媒体

    • songloft 面向个人用户的自托管音乐服务器
    • stremio-web Stremio 官方 Web UI，一站式视频娱乐媒体中心，支持插件、同步、投屏和 PWA 安装
    • melody 个人音乐云盘
    • PeerTube 采用 ActivityPub 联邦协议、可在浏览器内直接通过 P2P 点对点 传输的视频流媒体平台
    • immich 高性能自托管照片与视频管理解决方案

    #网站服务

    • YOURLS 短链接工具(PHP)
    • shlink 短链接工具(PHP)
    • openGym 自托管的健身与体重追踪应用，支持周计划、训练记录、PWA 与 Docker 部署
    • postiz-app 自托管的社媒内容排期与发布平台，支持多平台分发和自动化工作流
    • Ghost 为现代出版、会员体系、订阅服务与新闻通讯提供自主技术。
    • tinacms 一款完全开源的无头 CMS，支持 Markdown 与可视化编辑。
    • emdash EmDash 是一款基于 Astro 构建的全栈 TypeScript 内容管理系统，堪称 WordPress 的理念继任者。
