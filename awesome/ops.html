    #运维

    收录数据库、部署、网络、终端和可观测性等基础设施与运维工具。面向个人或团队业务的应用见自托管。

    #部署

    • coolify 一款开源、可自托管的 PaaS 平台，可作为 Vercel、Heroku 和 Netlify 的替代方案，让你轻松在自己的服务器上部署静态站点、数据库、全栈应用以及 280+ 个一键式服务
    • dokploy Vercel、Netlify 和 Heroku 的开源替代方案
    • 1Panel VPS 服务器管理面板
    • sst 依托自有基础设施搭建全栈应用

    #虚拟化与容器

    #虚拟机与沙箱

    • firecracker 面向无服务器计算的安全高速微虚拟机
    • muvm 基于 libkrun 在 microVM 中运行本机程序，支持图形应用、GPU 加速和跨架构运行
    • mxc 沙箱执行容器
    • clone 用于多租户开发环境与无服务器架构的轻量级虚拟机监控器

    #容器与编排

    • colima 可在 macOS（以及 Linux）系统上极简部署使用的容器运行时
    • rootlesskit 基于用户命名空间的 Linux 原生伪根工具
    • talos 一款专为 Kubernetes 打造的现代 Linux 发行版
    • dpanel 轻量化 docker 可视化管理面板
    • watchtower 自动实现 Docker 容器镜像更新
    • oras OCI 容器镜像仓库客户端——用于管理制品、镜像、软件包等内容
    • karmada 开放、多云、多集群 Kubernetes 编排
    • containerd 一个开源且可靠的容器运行时

    • 3x-ui 支持多协议和多用户的 Xray 管理面板，具备到期天数、流量及 IP 限制功能（支持 Vmess、Vless、Trojan、Shadowsocks、Wireguard、Hysteria、隧道、混合模式、HTTP、TUN 模式）

    • untun 借助 Cloudflare 快速隧道，将本地 HTTP/HTTPS 服务暴露至公网
