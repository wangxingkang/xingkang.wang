    #训练与评测

    • peft 最先进的参数高效微调
    • LlamaFactory 面向 100+ LLM 与 VLM 的统一高效微调框架，提供零代码 CLI 与 Web UI
    • datasets 最大的即用型 AI 模型数据集中心，配备快速、易用、高效的数据处理工具
    • pytorch 深度学习框架
    • DeepSpec 一套用于训练与评估推测解码算法的全栈代码库
    • OpenMythos 依托现有公开研究文献，从基础原理出发，对克劳德神话架构进行理论重构
    • rotorquant 采用分块对角旋转实现键值缓存压缩，性能优于极速量化：困惑度 6.91，优于 7.07；解码速度提升 28%，预填充速度提升 5.3 倍，参数量缩减至原有的 1/44，可直接无缝接入 llama.cpp 使用
    • unsloth Unsloth Studio 是一款网页界面工具，可在本地训练并运行 Gemma 4、通义千问 3.6、DeepSeek、开源版 GPT 等开源模型
    • NeMo 一款可扩展的生成式 AI 框架，专为从事大语言模型、多模态及语音 AI（自动语音识别与文本转语音）研究与开发的研究人员和开发者打造。
    • inspect_ai 一款面向大语言模型评估的框架
