# IDE

## 编辑器

- [sidex](https://github.com/Sidenai/sidex) 基于 Tauri 重构的 VS Code。架构保持一致，体积缩减 96%。目前为早期版本

## VsCode

### 插件

- [vscode-office](https://github.com/cweijan/vscode-office) 让 VS Code 支持预览 PDF、Excel、Word 等格式文件，并新增所见即所得的 Markdown 编辑器
- [turbo-console-log](https://github.com/Chakroun-Anas/turbo-console-log) 自动化日志工具
